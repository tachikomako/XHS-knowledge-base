# Chrome 扩展

Manifest V3 本地优先扩展，支持剪藏当前帖子，并同步收藏页中已经加载的卡片。

## 当前能力

- 预览当前帖子的标题、作者、正文快照和图片数量；
- 用户点击后，将帖子发送给本地 Spring Boot API；
- 在“我的收藏”页面预览已加载卡片数量，经用户确认后每 50 条分批同步；
- 配置本地后端、知识库地址和访问令牌；
- 不读取或上传 Cookie、密码、验证码，不调用私有接口，不在后台爬取。

## 本地加载

在 `chrome://extensions` 开启开发者模式，选择“加载已解压的扩展程序”，然后选择本目录。启动后端并在弹窗中填写与 `XHS_EXTENSION_TOKEN` 相同的令牌，再打开或刷新一个小红书帖子页。

批量初始化时进入个人主页的“收藏”标签，先向下滚动让目标卡片加载，再打开扩展查看数量并确认同步。扩展不会自动滚动；重复同步由后端幂等去重。

默认地址：

- 后端：`http://127.0.0.1:8080`
- 知识库：`http://127.0.0.1:5173`

运行 `npm test` 可执行基于脱敏 HTML fixture 的采集器测试。Manifest V3 不允许远程托管扩展代码，本扩展所有 JavaScript 均包含在仓库中。
