# Chrome 扩展

Manifest V3 本地优先扩展，支持剪藏当前帖子，并在用户点击后同步收藏和点赞列表。

## 当前能力

- 预览当前帖子的标题、作者和正文；
- 用户点击后，将帖子发送给本地 Spring Boot API；
- 在个人主页由用户手动启动一次同步，自动进入收藏/点赞标签、滚动发现卡片并每 50 条分批导入；
- 显示最近一次同步任务的发现、处理、新增、更新、未变化和失败数量；
- 配置本地后端、知识库地址和访问令牌；
- 不读取或上传 Cookie、密码、验证码，不调用私有接口，不做定时或实时同步。

## 本地加载

在 `chrome://extensions` 开启开发者模式，选择“加载已解压的扩展程序”，然后选择本目录。启动后端并在弹窗中填写与 `XHS_EXTENSION_TOKEN` 相同的令牌，再打开或刷新一个小红书帖子页。

批量初始化时进入个人主页，选择“我的收藏”和/或“我的点赞”，点击“开始同步”。扩展只在这次任务里自动切换标签和滚动，任务完成后停止；重复同步由后端幂等去重。

滚动加载更多内容后可以直接点击“重新扫描”。如果仍识别为 0，展开“适配诊断”并复制其中的数字统计；诊断不包含帖子标题、正文、用户 ID、Cookie 或页面地址。

默认地址：

- 后端：`http://127.0.0.1:8080`
- 知识库：`http://127.0.0.1:5173`

运行 `npm test` 可执行基于脱敏 HTML fixture 的采集器测试。Manifest V3 不允许远程托管扩展代码，本扩展所有 JavaScript 均包含在仓库中。
